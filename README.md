# Lagoon Arcade

ブラウザだけで遊べる自作ゲーム集です。インストールも会員登録もいりません。入口はリポジトリ直下の `index.html` (一覧ページ) で、ゲームは1本ずつ `games/<slug>/` に入っています。

**▶ [一覧ページを開く](https://denden047.github.io/lagoon-arcade/)**

すべて素の HTML + Canvas + JavaScript で書かれていて、ビルド工程も外部ライブラリもありません。セーブデータは各端末のブラウザ (localStorage) にだけ残り、サーバーには送られません。

| フォルダ | 内容 |
|---|---|
| [games/mantis-keeper](games/mantis-keeper/) | カマキリ飼育日記。オオカマキリを1齢の幼虫から育てて卵鞘を産ませ、次の世代へつなぐ育成ゲーム |

## ローカルで動かす

`file://` から開くとブラウザのセキュリティ制限に引っかかるので、簡易サーバーを立てて開きます。

```bash
python3 -m http.server 8802
open http://127.0.0.1:8802/
```

## ゲームを1本足す

1. `games/<slug>/` にゲームを置く（入口は `index.html`）。
2. `games.js` の `GAMES` に1件足す。日本語と英語のタイトル・紹介文、ジャンル、プレイ人数、公開日を書く。新しいジャンルなら `GENRES` にも足す。
3. `./tools/capture-thumbs.sh <slug>` でサムネイルを作る。`assets/thumbs/<slug>.jpg` に出る。
4. 出来た画像を目で見て確認する。
5. この README の表に1行足す。

一覧ページはこの `games.js` だけを読んで組み立てるので、他に直す場所はありません。
